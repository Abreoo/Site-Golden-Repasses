 Golden Repasses

Site para divulgação de veículos de repasse.

Tecnologias utilizadas

- React
- Vite
- TypeScript
- Node.js
- Express

Funcionalidades

- Listagem de veículos
- Contato direto com consultores via WhatsApp
- Interface moderna e responsiva

 Como rodar o projeto

1. Clonar o repositório

git clone https://github.com/Abreoo/Site-Golden-Repasses

2. Instalar dependências

npm install

3. Rodar o projeto

npm run dev
